# Release visual review

The final scores are pending the signed APK built from the final source revision. Earlier diagnostic screenshots are not a final release pass.

Required categories (0–5): alignment, typography, hierarchy, density, discoverability, consistency, responsive layout, Results readability, Geometry usability, Conditions usability, Sweep usability, overall polish.

Required profiles: 320×568 / 100%; 320×568 / 130%; 360×780; 393×873; 412×915; 600×960; 768×1024; 915×412; 1024×600. Inspect both themes and the Geometry top/derived/aerodynamics, Conditions top/bottom, Results top/middle/bottom and Sweep captures.

An objective, correctable defect below 4.8 is a rework item. Passing bounds/source tests alone does not justify a visual score. Record screenshot paths, actual inspection and limitations with the final matrix.
