RotorCalculator — Physics & Equations

Offline reference for the zBET analytical rotor model used by RotorCalculator. UI conventions and equations follow zBET/zBEMT.

1. Coordinate and sign convention

QuantityPositive meaning
+x, VxForward, in the rotor plane.
+yStarboard / right side.
+zDownward through the rotor disk.
Vz > 0Positive climb rate; relative wind arrives from above and flows downward through the disk.
μz > 0Positive downward relative-flow ratio.
α > 0Relative wind arrives from below the disk.
T > 0Upward rotor thrust, along −z.
λi ≥ 0Induced downwash in +z.
μ = Vx / (ΩR)
μz = Vz / (ΩR)
μz = −μ tan(α)
λ = μz + λi
Equivalent inputs: α, Vz and μz describe one axial condition. They are alternatives, not additive terms. At Vx=0, use Vz or μz for non-zero axial flow.

2. Reference blade geometry

Geometry uses a reference linear planform from the rotor axis to the tip. Root cutout defines where the active aerodynamic blade begins; it does not redefine the reference chord law.

c(x) = c0 + (c1 − c0)x,   0 ≤ x ≤ 1
Sref,b = R(c0+c1)/2
AR = R²/Sref,b = 2R/(c0+c1)
σref = Nb Sref,b/(πR²) = Nb/(π AR)
σgeom = Nb/(πR) ∫[x0..1] c(x) dx
σthrust = 3 ∫[x0..1] x² σ(x) dx

Changing radius scales c0 and c1 proportionally, preserving σref, AR and taper. Changing σref or AR scales both chords with constant taper. Root and tip incidence define baseline twist.

3. Collective and operating constraints

Operating collective is one constant pitch increment along the blade:

θroot,op = θroot + Δθ    θtip,op = θtip + Δθ

The operating state contains four linked quantities: RPM, Δθ, CT and thrust. Conditions lets you prescribe any two:

Prescribed pairSolved quantities
RPM + CollectiveCT and thrust
RPM + CTCollective and thrust
RPM + ThrustCollective and CT
Collective + CTRPM and thrust when the flight/model state provides a unique dimensional solution
Collective + ThrustRPM and CT
CT + ThrustRPM and collective
Trim is performed at the current flight condition, including forward flight and climb/descent. If RPM changes, dimensional Vx and Vz are re-nondimensionalized at each candidate RPM.

4. Mean inflow and momentum closure

CT,momentum = 2 B² λi √(μ² + λ²)
CT,BET = CT,BET(μ, λ, pitch, geometry, inflow gradients)

zBET solves λi ≥ 0 so blade-element thrust and momentum theory agree. If no physical root exists, the point is marked invalid.

6. Profile drag, tip loss and compressibility

Profile drag

RotorCalculator always uses Numerical Vectorial radial/azimuthal integration for profile drag. It is not a user-selectable approximation.

Tip loss

Available tip-loss choices are None, Fixed B and Sissingh.

B(Sissingh) = 1 − √(2CT)/Nb

Sissingh B, inflow and CT are iterated to mutual consistency.

Prandtl–Glauert

Meff = (ΩR/asound) √(0.75² + 0.5μ²)
a(Meff) = a0 / √max(0.01, 1−Meff²),   Meff ≤ 0.85

Advancing-tip Mach Mat = ΩR(1+μ)/asound is reported separately and generates a caution from Mat=0.80 when the correction is enabled.

7. Torque, power and Kind

CQ = CQi + CQ0
Pshaft = QΩ
CQi = Kind λi CT + μz CT − μ CHi
CPair = Kind λi CT + μz CT + CQ0 + μ CH0 = CQ + μCH

Kind is the induced-power factor entered in Conditions. CPair is air power; CQ is shaft torque/power coefficient.

8. Efficiency

FoM = (CT^(3/2)/√2) / [Kind CT^(3/2)/√2 + CQ0]
(L/D)eff = μ CT / CPair

9. Results

Results groups outputs as Dimensional Performance, all Aerodynamic Coefficients together, Efficiency, Inflow & Wake, and Operating State & Atmosphere.

The final section explicitly reports solved RPM, Δθ, CT, thrust, μ/Vx, μz/Vz/α, tip speed, Mach values, altitude, temperature, density, pressure and speed of sound.

10. Parameter sweeps

Any scalar Result can be plotted against μ, with Vx as an equivalent x-axis display. Curve families are Active Only, Inflow Models, α, Vz and μz. Family values can be edited with the VALUES control.

Plot, TABLE and CSV share the same sampled dataset. Invalid samples appear as gaps.

Trim only in hover: when CT or thrust is prescribed, OFF re-trims every sweep point. ON trims once at μ=0, μz=0 and then holds that solved RPM and collective throughout the sweep.

12. Model scope

  • Linear section lift curve and baseline constant Cd0.
  • No dynamic stall, cyclic trim, blade structural dynamics or free wake.
  • First-harmonic prescribed inflow gradients.
  • Conceptual/preliminary rotor performance use, not certification-level loads analysis.
