RotorCalculator — Physics & Equations

Offline reference for the zBET analytical rotor model used by RotorCalculator. Conventions are aligned with zBET and zBEMT.

1. Coordinate and sign convention

QuantityPositive direction / meaning
+x, VxForward, in the rotor plane.
+yStarboard / right side.
+z, VzDownward through the rotor disk.
T > 0Upward rotor thrust, along −z.
α > 0Rotor angle of attack: the free stream arrives from below the disk.
λi ≥ 0Induced downwash in +z.
μ = Vx / (ΩR)
μz = Vz / (ΩR)
μz = − μ tan(α)
λ = μz + λi
Important: α, Vz and μz are three equivalent ways to prescribe the same axial operating condition. RotorCalculator never adds them together. At Vx = 0, use Vz or μz for non-zero axial flow because α is not a unique representation there.

2. Geometry

The lifting span is defined by radius R, root cutout x0=r0/R, blade count N, root/tip chord, and root/tip pitch. The visible chord fields are the authoritative planform input.

A = πR²
Ω = RPM · 2π / 60
Vtip = ΩR

Linear chord and twist are interpolated between root and tip. The section model uses a linear lift-curve slope a0 and constant baseline profile drag Cd0.

3. Mean inflow and momentum closure

For a given flight condition, zBET solves the induced component λi from blade-element thrust and momentum balance. The induced solution is constrained to a physical non-negative root.

CT,momentum = 2 B² λi √( μ² + λ² )
CT,BET = CT,BET( μ, λ, pitch, geometry, inflow gradients )

The solver finds λi such that both expressions agree. If no physical root is bracketed, the operating point is explicitly marked invalid.

5. Tip loss and compressibility

Sissingh effective tip radius

B = 1 − √(2CT) / N

RotorCalculator iterates the coupling between B, inflow and CT to convergence. This is an engineering effective-radius approximation.

Prandtl–Glauert

a(M) = a0 / √(1 − M²)

The app flags a caution when advancing-tip Mach reaches 0.80 while the correction is enabled. The linear correction should not be interpreted as a transonic airfoil model.

6. Torque and power

CQ = CQi + CQ0
Pshaft = Q Ω
CPair = Kind λi CT + μz CT + CQ0 + μ CH0

With the energy-balance torque closure:

CQi = Kind λi CT + μz CT − μ CHi
CPair = CQ + μ CH

CPair is air power. CQ is shaft torque coefficient. They are related, but they are not interchangeable labels.

7. Efficiency metrics

FoM = (CT^(3/2)/√2) / [ Kind CT^(3/2)/√2 + CQ0 ]
(L/D)eff = μ CT / CPair

Figure of Merit is a hover efficiency metric. Effective rotor L/D is meaningful in forward flight when air power is positive.

8. Trim modes

ModeWhat is solved
Manual PitchPitch and RPM are prescribed; thrust is an output.
Collective to Thrust / CTRPM and blade twist are fixed; collective is shifted to meet the target.
RPM to ThrustPitch is fixed; RPM is solved to meet a dimensional thrust target.

9. Parameter sweeps

The sweep changes horizontal flight state while cloning the active condition; it never changes the live operating point. The x-axis may be displayed as μ or Vx. Multi-curve comparisons can use inflow model, α, Vz or μz families.

When α is selected as the axial representation, varying μ changes μz according to μz = −μ tanα. When Vz or μz is selected, the corresponding physical quantity is held fixed across the sweep.

11. Model scope

  • Linear section lift curve and constant baseline Cd0.
  • No dynamic stall, cyclic trim, blade structural dynamics or free wake.
  • First-harmonic prescribed inflow gradients.
  • Conceptual / preliminary rotor performance use, not certification-level loads analysis.
